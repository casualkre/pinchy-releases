# Notes and artifacts: where longer answers go

Pinchy's chat bubble is small on purpose. Anything longer than a few sentences goes into a note on your desktop, and anything visual or substantial becomes an artifact you can open, change and keep.

## What to ask for
- "Put my shopping list in a note." A note window appears on your desktop.
- "Give me the commands to set this up." You get a note with the commands in code blocks; each block has its own copy button.
- "Make me a small page with a five-minute timer." An artifact: it opens in its own viewer.
- "Make the timer ten minutes instead." He updates the same artifact; the earlier version is kept.
- "Show me that screenshot again." He opens the picture in a window.

## How it works
- Notes: text in a note can be selected and copied like any text. A whole section or a single code block can be copied with one click. Dragging the note moves it; dragging over text selects it.
- Artifacts: pages, mini apps, diagrams, reports, tables and code files. Each opens in a sandboxed viewer and keeps its versions, so "change it" never loses what was there before.
- Files a job made (a Work run, a swarm, a plain chat reply that wrote a file) are attached in the chat as cards you can open.

## Settings
- Settings → Pinchy → Notifications: how notes and results are shown.
- Settings → Agents & automation → Agents: open long results as a note window.
- Settings → Pinchy → Look & behaviour: how he behaves on your desktop.

## Limits
- An artifact page is self-contained and cannot reach the internet from its viewer.
- Notes are for reading and copying. For a document you want to keep editing, ask for a file (Work mode makes real documents).
