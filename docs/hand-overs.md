# What your agents and krill hand you

Work Pinchy, his agents and krill make for you lands in the Reef as a space document, not as a loose .md file. It has the name of whoever made it on it, you can edit it like any other document, and the next time the same report is due the same document is updated (the old versions stay in its history). A file (.docx, .pdf, .xlsx) is still made when you ask for that format.

## Where it lands
- An agent has a space of its own, named after it. Its reports go there and stay one document per report: a daily report is one document with a version per day, not thirty files.
- A krill working on a space puts its result in that space. A krill an agent started puts it in that agent's space. A krill you or Pinchy started puts it in your home space.
- If you edited a report yourself, the agent does not rewrite it over your words next time: it changes only the parts that are new, so your edits stay.
- An agent or krill that still writes an .md file (some engines do) is not lost: the file is also put in the Reef as a document, and the same file next time updates the same document.

## @mention an agent in a document
- Type @ and the agent's name (the @ menu lists them, or just write "@Scout"). When you stop typing, the agent gets a note with the document and the line you wrote. It sees it in its next round.
- Its answer comes back as a comment on that line, with its name. It may also change the document where you asked, or decide not to answer.
- Each @ is sent once. Editing the words around it later does not send it again. @Pinchy works the same way.
- @krill (from the @ menu) hands that line to the document's own krill: it starts working on the document right away, or takes the new line into the job it is already doing. Only your own @krill starts it; an agent writing @krill does not start paid work.
- Agents can @mention each other in documents too; the note is information for the other agent, never an order it has to follow.

## Keep a document up to date
- Open the document and press "Keep updated": pick how often (every few hours, daily, weekly, at a time of day, on some days) and, if you like, say what should stay current ("GPU prices in Turkey", "the release dates").
- Every so often a krill reads the document, finds what went out of date, and fixes it in place (never a new document). It writes one line about what it changed and where it found it, or says nothing was out of date.
- Only you, or Pinchy when you ask him, can switch this on. Agents and krill cannot start these runs by themselves.
- "Update it now" runs it once without a schedule. A run that fails waits a little longer before the next try. Switch it off from the same button.

## What to ask for
- "Put that in a document" / "Give me that as a report." Pinchy, an agent or a krill makes a space document in the Reef.
- "Update the weekly report" — the same document gets a new version, not a copy.
- "Keep this document up to date every morning at 9." Pinchy switches Keep updated on for it.
- "Which documents are kept up to date?" He lists them with when each last ran and when it runs next.

## Settings
- None of their own: "Keep updated" and its schedule live on each document (the button in the document's header, also on the phone).
- Settings → Agents & automation: an agent's model and how it delivers (its report also lands in its space either way).
