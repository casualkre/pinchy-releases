# Notes and files

Pinchy's chat bubble is small on purpose. Anything longer than a few sentences goes into a note on your desktop, anything visual or substantial becomes an item in a space (see the Spaces page), and any file — yours or one he made — shows as a card you can preview and download.

## What to ask for
- "Put my shopping list in a note." A note window appears on your desktop.
- "Give me the commands to set this up." You get a note with the commands in code blocks; each block has its own copy button.
- Attach a PDF, a .zip or a whole folder and say "summarise this" or "fix the bug in this project". He reads it.
- "Show me that screenshot again." He opens the picture in a window.

## How it works
- Notes: text in a note can be selected and copied like any text. A whole section or a single code block can be copied with one click. Dragging the note moves it; dragging over text selects it.
- Attaching: every message box has one attach button. In the chat bubble it is Attach → Screenshot · Files… · A folder…; in Agents → Workspace the paperclip offers Files… and A folder…; in an agent's chat it is Attach plus a Folder button. You can also drop files or folders on the box, or paste a screenshot into it (the chat bubble takes any pasted file up to 50 MB).
- Any kind of file can be attached: documents, PDFs, pictures, sound, video, .zip files and whole folders. Each shows as a card with its name and size; a folder card says how many files it holds.
- In the plain chat he works on the file or folder where it is, so "fix the bug in this folder" changes your folder. Krill and agents get their own copy to work in.
- Pinchy keeps a copy of what you attached, so the conversation still shows exactly what was sent even if you later change or delete the original.
- Files he makes come back the same way: a krill, a swarm, an agent, or a plain chat reply that wrote a document shows its files as cards under the message.
- Click a card to open the Preview window. It shows:
  - pictures at full size (click to see the real size),
  - PDFs in a built-in PDF viewer,
  - sound and video with a player,
  - text, notes, code and data files as text (pages and SVG pictures are shown as their text, never run),
  - folders and .zip files as a list; click a file in the list to preview it, and the back arrow returns to the list.
- The Preview window's buttons: Download (Save As, to your Downloads folder by default; a folder downloads as one .zip), Open with app (the app your computer uses for that kind of file; for a folder: Open folder) and Show in folder. Inside a folder or zip, Download saves just that file, and Download all as zip saves everything.
- Point at a card for its quick buttons: Preview, Download, Show in folder and Save to cloud.
- Save to cloud puts the file (or the whole folder) into your cloud storage, if you have set one up.
- From the phone app and from Telegram you can send files too; see the phone and Telegram pages.

## Settings
- Settings → Pinchy → Notifications: how notes and results are shown.
- Settings → Pinchy → Look & behaviour: how he behaves on your desktop.
- Settings → Safety & data → Backup & move → Open Cloud storage: set up the storage that Save to cloud uses. You can drop files and folders on the Cloud storage window.

## Limits
- Notes are for reading and copying. For a document you want to keep editing, ask for one: it lands in a space.
- A file can be up to 2 GB. A folder can hold up to 10 000 files and 2 GB in all; links inside a folder are left out. A pasted file can be up to 50 MB; attach bigger ones with Files….
- The Preview window shows the first 512 KB of a long text file; download it to see all of it.
- Inside a folder or a zip, only pictures and text files can be previewed. Only .zip files can be looked inside (not .rar, .7z or .tar).
- Word, Excel and PowerPoint files are not previewed inside Pinchy: use Open with app or Download.
- Open with app opens a private copy of the file. Anything that could run a program (scripts, pages, apps, unknown kinds) is only shown in its folder; open it yourself if you trust it.
- Save to cloud asks you to set up cloud storage first if you have none.
